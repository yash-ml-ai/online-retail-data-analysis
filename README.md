# Online Retail Data Analysis

## Project Overview
This project analyzes online retail transaction data to identify sales trends, top-selling products, country-wise revenue, and high-revenue customers using Python.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Steps
- Data cleaning and preparation
- Handling missing values and cancelled invoices
- Removing invalid quantities and prices
- Revenue calculation
- Exploratory Data Analysis (EDA)
- Data visualization and business insights

## Key Findings
- November 2011 recorded the highest monthly revenue.
- The United Kingdom generated the highest country-wise revenue.
- PAPER CRAFT, LITTLE BIRDIE was the top-selling product by quantity.
- Customer 14646 generated the highest customer revenue.

## Project File
- `Online Retail Data Analysis.ipynb` — notebook containing the analysis, code, and visualizations.
